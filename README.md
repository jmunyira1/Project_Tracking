Project Tracking

A clean and intuitive project tracking tool designed for teams and individuals who want a simple way to monitor progress. It helps you move from scattered notes to a structured overview of all your work.

The application is built around the core idea of projects and tasks, providing a clear dashboard to see what's been done and what still needs attention.

✨ Key Features

**Project Dashboard**
Get an immediate overview of all your projects from the main dashboard. See each project's progress at a glance, with visual indicators for the number of tasks completed versus those still pending, helping you prioritise your work effectively.

**Create and Manage Projects**
Easily set up new projects by giving them a name and a description. Once created, you can view the details of any project, update its information as things change, or remove it completely when it's finished.

**Task Management Within Projects**
Break down any project into smaller, actionable tasks. For each task, you can add a description and mark it as complete when done. This helps you focus on one step at a time and clearly see the progress you're making within a larger piece of work.

**Progress Tracking**
The system automatically calculates and displays the progress of each project based on its completed tasks. This gives you and your team an instant, motivating visual cue on how close a project is to completion without needing to run any manual reports.
